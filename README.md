# 🦸 Teen Titans GO! — Baby Hands Crisis

> *A browser-based 2D action-platformer built for a gaming hackathon.*

Robin's been cursed with baby hands — and Brother Blood is using the chaos to take over Jump City. Can the Titans save the day (baby hands and all)?

---

## 🎮 Gameplay

Play as Robin and battle through Jump City in this pixel-art inspired side-scroller. Dodge enemies, collect points, and race against the clock — all while Robin awkwardly fights crime with tiny little hands.

### Screens
- **Title Screen** — Choose your destiny (and meet the Titans in glorious pixel form)
- **Cutscene** — Story-driven dialogue panels between chapters
- **Game** — Canvas-based action with a live HUD (lives, score, timer, chapter)
- **Win Screen** — 🏆 Titans Assemble! Jump City is saved!
- **Game Over** — 💀 Brother Blood wins... this time.

## 🛠️ Tech Stack

Built entirely with vanilla web tech — no frameworks, no dependencies.

- **HTML5** — Game structure and screens
- **CSS3** — Pixel art styling, animations, and responsive layout
- **JavaScript (Canvas API)** — Game loop, physics, collision, rendering, and HUD

```
teen-tinas-go-game/
├── index.html   # Game screens & layout
├── style.css    # Pixel art styles & animations
└── game.js      # Core game engine & logic
```

---

## 🚀 Getting Started

No build step. No install. Just open and play.

```bash
git clone https://github.com/084divyanshuraj/teen-tinas-go-game.git
cd teen-tinas-go-game
```

Then open `index.html` in your browser — or serve it locally:

```bash
# Python
python -m http.server 8000

# Node.js (npx)
npx serve .
```

Navigate to `http://localhost:8000` and hit **▶ START GAME**.
